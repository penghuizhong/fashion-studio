# Fashion Studio 0.6.0

## 图片和下载

- 原图直接保存模型接口返回的字节；另生成最长边 600px、保持宽高比的 JPEG 82 缩略图。收为款式卡只关联原文件，不重编码、缩放或裁切原图。
- 新原图按真实格式命名。历史路径和文件保留原样；通过 `?download=1` 下载时识别真实格式并设置附件文件名及 MIME。
- 创意结果、款式生成记录、素材详情均可下载原图；多用户请求校验会话与所属用户，文件不经前端画布导出。

## 款式卡与大图

- 封面容器改为 1:1，使用等比完整显示，横图和竖图允许留白；其他相关预览不再使用 cover 裁切。
- 点击款式卡按需加载对应原图，支持适应窗口/实际尺寸查看、下载、Esc 关闭；标题和操作区不随原图滚动。
- 款式属性保留独立按钮，大图也可进入；列表接口提供与封面缩略图对应的原图路径。

## 验证与发布

客户端、服务端及两个 lockfile 统一为 0.6.0。发布使用功能分支提交、main 合并提交和指向合并提交的 annotated tag `v0.6.0`；GitHub Validate 覆盖 main 与 feat/**。

本地验证命令：

```sh
npm --prefix server run check
CHECK_MODE=multi npm --prefix server run check
npm --prefix server run check:explore
npm --prefix client run test:e2e
```

本地最终自检：单用户 62/62、多用户 64/64、专项 38/38、Chromium 5/5，生产构建通过；版本与 lockfile 一致，Git 空白检查通过。浏览器测试包含生产构建。专项验证原图字节及尺寸、缩略图比例、正确下载、历史格式兼容、跨用户权限，以及款式卡列表原图路径；浏览器覆盖 1:1 容器、完整显示、下载、大图原文件、实际尺寸、Esc 与属性入口。

## 数据与回滚

本版无数据库迁移，不重写已有原图。新增图片可能使用 .png/.webp 等真实扩展名，原图及缩略图路径由已有数据库字段保存。回滚至 0.5.0 应保留整个 DATA_DIR 和所有扩展名的文件；不删除上传目录或修改账本。回滚前停止服务，部署上一 main 提交 fa4cc4c 后重启。

真实供应商图像质量、视觉效果及生产站点表现不由模拟供应商测试证明。整套弹窗步骤导航和固定头尾的 UI 重构仍属于后续事项。
