日期：2026-10-20。状态：本地实现与自检完成，尚未推送、合并或部署。前后端package及锁文件统一为0.12.0，未增加运行依赖。逐项证据见 [38项执行TODO](STYLE_DERIVATION_WIZARD_TODO.md)，设计依据见 [方案](STYLE_DERIVATION_WIZARD_PLAN.md)。

## 使用流程

1. **款式属性**：左侧选择版本、查看只读属性；修改必须保存为新版本，原属性与图片保留。右侧优先显示轻量预览，完整图片与原图按需加载。新版本无图时明确标注父版图片只是参考。
2. **需求分析**：统一参考入口并区分商品、模特、面料和场景角色，填写要求及已确认资料，选择详情模块和生成参数。先展示分析模型、思考控制及费用，显式确认才调用分析。右侧显示持久任务的实际阶段与逐项完成数量；关闭后可恢复。
3. **方案预览**：编辑整体规范及每张图片的标题、画面要求、文案、参考和取景。提示词按目标、设计、参考、构图、文案、限制和输出规格组织；手工覆盖与自动编译分开，可对比和恢复。提交使用当前展示的最终提示词。构图示意不调用模型；本轮未增加独立付费试生成入口。
4. **生成中**：显示排队、运行、成功、失败及待核对结果，成功图可即时查看。关闭弹窗不停止后台任务；运行中回看不会再次提交生成。
5. **完成**：当前批次优先，历史按需分页；图片直接关联本款式、设计版本、规划修订、批次和稳定规划项，不需要再次收卡。支持原图大图、单图下载、保留原字节的ZIP批量下载、封面、归档、回收站、恢复和继续衍生。失败重试沿用原快照，仅重新报价明确失败的项。

桌面以38/62左右分屏，固定标题、关闭、步骤和底部操作，正文按列滚动；手机使用设置/预览切换。颜色使用已有主题语义变量。纯看图模式仍只请求轻量工作区和预览，不提前加载模型、参考列表或全部历史。

## 模块、版本与计费

- 19类模块包含主图、品牌、卖点、面料、版型、颜色尺码、多色、促销、规格、洗护、售后、常见问题、买家秀、搭配、场景、博主、平铺、挂架及过渡卡；默认先展示6类。每类最多16张，总上限64；保留创意发散原有数量上限，供应商调用仍按原队列并发执行。
- 模块数量、整体规范、逐图编辑属于图片规划及其修订。服装设计变化属于另存的不可变设计版本；生成批次固定提交时采用的版本、规划修订和提示词。已有三视角位置、人工核对和样衣交付条件保留。
- 可见图片观察与用户确认的商品资料分开。未提供尺码、成分、价格、品牌或售后资料的相关模块标为待补，不用AI推测值代替真实资料。平铺、挂架、局部特写及过渡卡拥有各自取景，不套用统一露脸要求。
- 分析模型与图片模型分别选择；有参考图的分析要求管理员声明视觉能力。思考模式按模型的可切换、固定开启、不支持或尽力传递能力显示；尽力传递不代表供应商保证执行。
- 分析复用现有预留、按真实usage结算和退款机制；实际结果未知或缺usage时保留待核对，不自动重试收费。分析和生图分别确认，前端不把编辑、切步骤或构图示意当作付费操作。
- 生图按每图实际尺寸、质量和注册模型报价并冻结快照。确认时再次校验规划修订、模型和价格；响应丢失使用原请求标识恢复，不自动新建任务。并发规划编辑显式对比合并，保留未冲突的远端内容和本地手工覆盖。
- 上传与生成原图不重编码、不强制裁切；展示使用独立缩略图/预览。批量下载取原图字节，最多2路并发，单图失败会报告其数量，不把坏文件当成功图片。

## 数据升级与回滚

启动时通过事务执行幂等增量迁移，新增`style_plans`、`style_plan_revisions`、`style_plan_requests`、`style_plan_analyses`及归属索引。不改写旧设计版本、图片字节和历史任务；旧REST接口保留兼容，旧单次生成草稿迁入新界面。历史缺少可靠版本关联时仍显示来源未记录。

升级前停止服务写入，等待在途模型任务完成或明确核对后，再备份数据库与整个uploads。现有部署流程会停服务并执行完整备份；手工升级也应使用仓库根目录下的现有脚本，备份目标必须是DATA_DIR外尚不存在的新目录：

```bash
node server/scripts/backup-style-upgrade.js /actual/DATA_DIR /safe/new-backup-dir
```

脚本使用SQLite备份接口、校验数据库并复制uploads。应用启动时的建表事务不替代完整备份。规划修订中引用的图片路径加入已有共享文件保护；删除资产记录不会误删仍被规划或历史引用的文件。

回滚先停写并备份当前完整数据，核对在途分析/生成及积分后，配套恢复升级前数据库和uploads，再运行对应旧代码。不能仅降级代码后继续处理新版本的逐图规格任务。恢复旧快照会丢失之后写入，需预先保留相关业务与计费审计；本轮没有执行生产回滚。已下线的layouts编辑、画布和导出接口继续下线。
