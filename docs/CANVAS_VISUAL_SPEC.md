## 布局原则
- 画布和Agent分栏。图层、导航和工具浮在画布上，不占据独立应用导航列。
- 图层约190px，Agent约43%（桌面最小330px，最大760px），大圆角、细边框和轻阴影。最终比例需在用户原始视口下进一步对齐。
- 紫色用于选框、选择状态和助手标记；黑色发送按钮沿用当前主题的主按钮。
- 生成结果与输入建立持久化血缘，缩略导航显示连接；主画布不擅自增加醒目箭头。
- 当前版本手机采用画布与助手纵向排列，属于可用性适配，不是已验证的原站手机布局。
- 不复制原站账户、额度、示例生成结果或未接通的菜单，不将模拟供应商测试图当成真实视觉效果。
