# 服装商品图质量优化 TODO

日期：2026-10-21  
目标：同款服装高保真、主图干净、卖点准确、中文可读，产出可用于上架的商品图。

保留五步界面：款式属性 → 需求分析 → 方案预览 → 生成中 → 完成。先做好主图展示、款式卖点两个模块，再推广到其他模块。本清单记录代码实施状态；功能通过与真实模型成图质量分别验收。

## 当前证据与待核实问题

- 用户提供的两份项目提示词均显示“无参考图片，使用已保存属性”。需要核对生成当时的任务快照与实际请求，确认是缺图、引用丢失，还是编辑框与历史任务不同步；尚不能直接认定原图没有发送。
- 卖点分析加入“动态模糊、裙摆飞扬、穿透薄纱、强化通透感”，缺少原图依据，会引导材质和服装形态变化。
- 主图混入通用详情规则，卖点模板过度依赖模特姿态，模块边界不明确。
- Shopix 截图显示另一个提示词预览框，但完整内容与实际请求未知，不将推测的隐藏逻辑当作事实或实施依据。
- v0.16.0 已有提示词编排、手稿保存和报价快照机制；本次在其基础上优化，不重复建设。功能检查通过与成图质量达标分别记录。

## 本轮已实施与剩余边界

- 原图链路、字节摘要冻结、卖点裁切、逐字中文、人工验收已落地；商品图与模特图均发送真实文件，不再把编号视作人物图。
