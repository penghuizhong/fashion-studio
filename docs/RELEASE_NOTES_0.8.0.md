# Fashion Studio 0.8.0（本地实现，未发布）

## 本轮行为

- 创意衍生、款式衍生共用结构化视角与取景：展示方式、朝向、相机角度、完整单品/全身/局部、主体大小及套装范围。标准对比默认正面平视、居中留白；平铺和特写校验组合，按类目描述服装完整边界。
- 创意报价、请求与任务快照保存拍摄参数；参数修改重新报价，失败重试保留原提示词和取景。历史未记录取景时明确说明，不用新默认值冒充旧设置。有拍摄约束时关闭供应商提示词扩展，并记录实际生效值。
- 一张款式卡包含不可变属性版本。编辑多个字段后一次保存一版，保存请求幂等，无实际值变化不制造重复版本；旧版不覆盖，能从旧版分支。数据库触发器保护属性和字段快照。
- 工作版本、当前查看版本、封面和编辑底图分开。新图片默认保留，不替换封面或基准；新版本无图时显示未生成。定稿作用于具体版本，仍可从它创建新版本。
- 原图和属性合并为同一个款式详情弹窗，左图右面板，支持展开/收起；手机上图下内容，图片可收起或放大。固定标题/关闭/底栏，中间滚动。属性默认阅读，分组编辑，人工确认与模型置信度分开。
- 六种衍生动作有专属表单和提示词。换色/改细节须对应已保存的设计变化；细节图指定部位，换背景只新增图片记录；同条件再生成与探索呈现变化分开。
- 明确按属性生成或基于图片修改；底图可选择原始参考和历史图片，不再取最新图作为隐式底图。辅助参考可上传或从有权限的资产选择，标注配色/面料/细节/画面用途。
- 模型使用注册 ID 路由，显示供应商、费用及编辑能力；原生尺寸按模型校验。模型管理增加“已验证图片编辑/多图参考”配置，只有当前适配器和模型配置都支持才开放，其他能力不静默降级。
- 款式衍生复用 explore_jobs / explore_items / explore_quotes 和原有积分预留、结算、失败退款、未知结果核对，统一供应商并发限制。内部工作批次不混入创意历史，也不能通过创意收卡接口采用错误属性。
- 结果在当前工作区比较和管理，支持查看、下载、显式设置展示图、以此继续衍生、另存款式、归档与恢复。永久删除需先归档并输入确认，引用中的图片拒绝删除。
- 旧“删除/回退”入口兼容为归档，保留原图；新批次全部失败时明确显示失败。桌面和手机都能访问关键操作。
- 呈现预设包含沿用底图、自动推荐、自然实拍、商品展示和品牌大片，示意与实际生成区分。套图约束写入提示词与快照，不能保证模型完全一致。
- 提供自由主图、白底、场景、特写用途；卖点/规格/集合图使用本地可编辑 SVG 排版层，组合已有原图，支持 SVG 和 PNG 导出。真实尺寸手动输入并换算 cm/in，确认资料后才能导出，不调用图片模型编造数据。
- 要求辅助采用本地整理当前属性的方式，确认后追加到原文，不新增模型调用。“输出语言”影响排版表头，正文仍由用户确认，不自动翻译。
- 克隆识图仅压缩分析副本，保存上传原始字节；新增浏览器用 1400×900 PNG 验证识图副本最长边 1024、保存原图字节与尺寸不变。历史已经压缩的源图不能恢复。
- 属性、生成设置及排版草稿按用户和款式/版本保存在当前浏览器标签页，24 小时有效；退出登录清理，不保存密钥或原图数据。

## 迁移与升级

新增 style_versions、style_version_requests、style_version_events、style_references、style_layouts，以及款式工作版本/封面/内部任务指针、图片版本/底图/任务/设置和批次类型列。旧款式当前属性捕获为迁移时初始版本，已有图片的历史设计属性没有证据时保持未知；不把它们强行关联初始版本。

移除启动时按空类目删除旧款式和原文件的旧清理逻辑。首次为有款式的数据库增加版本表前，用 SQLite VACUUM INTO 保存可读数据库备份到 DATA_DIR/backups。此自动数据库备份不能代替上线前整个 DATA_DIR 的完整快照。

升级前停止写入及旧服务，核对进行中和待确认的模型任务，确认实际 DATA_DIR，执行完整备份：

```sh
# 先停止服务；填写实际路径，不使用猜测的数据目录。
node server/scripts/backup-style-upgrade.js /实际/DATA_DIR /安全备份目录/升级前唯一目录
```

脚本使用 SQLite backup API、复制 uploads，并验证数据库完整性；备份目的地必须位于 DATA_DIR 外且不存在。迁移与备份脚本均通过临时旧库及文件验证。当前没有操作生产数据或执行生产升级。

## 限制与后续验收

- 真实供应商的构图、完整性和服装保持程度尚未验收；提示词、同 seed、多图参考均不能保证严格一致。自然语言冲突检测只覆盖明确组合及部分显式说法，不是通用语义判断。
- 图片编辑和 image[] 多图能力需管理员按实际供应商验证后启用。当前 DashScope 适配器仍仅文生图；蒙版、参考强度、负面提示词等没有经过适配器验证的参数不开放。
- 完整性自动质检已评估：当前不增加隐式模型检查或重生成费用，先提供明确取景和人工比较；自动识别疑似截断作为后续增强，不能把模型自评当作保证。
- 排版没有平台合规承诺，没有自动生成尺码、自动翻译或猜测不可见工艺。平台规则、实拍真实性及商品资料由用户核对。长文和极端比例应检查预览后导出。
- 实体手机软键盘/安全区和辅助阅读器需人工验收。语音、自由画板、复杂版本树及视频不属于本轮实现。
- 发布记录、远端 CI、main 合并、版本标签与线上验收均尚未执行，不用本地通过替代。

## 回滚

上一发布为 v0.7.0，main 合并提交 `81eb057`。本轮新增版本与内部任务数据，不能把“只切旧代码”视作完整回滚。优先停用新生成并向前修复；必须回滚时先停止服务，导出并核对上线后任务、图片、积分账本和待确认额度，再确定一致恢复点，恢复匹配数据库与 uploads 快照后部署旧代码。保留上线后新增文件的独立副本，不删除未知状态任务或盲目覆盖积分账目。

## 共享图片删除修复

已确认 v0.7.0 的单张删除及批量删除会直接 unlink 原图和缩略图，而创意收卡、分支款式及参考图可能共享同一文件路径。因此删除一条资产可能破坏其他款式、资产及历史任务的显示。

本分支普通删除改为逐条归档，不删除文件；资产库可筛选已归档并取消归档。永久删除同时检查原图和缩略图的跨记录、跨用户引用，以及任务结果、历史快照、报价、底图、封面、参考和排版引用；受引用的文件拒绝删除。检查与删除元数据置于立即事务内，文件暂存失败或数据库提交失败时回滚文件，原图与缩略图同路径只处理一次。

设计台、款式详情及资产库图片加载失败不再留下空白：缩略图失败时尝试原图，都不可用时显示缺失提示。资产接口返回原图和缩略图可用状态；仅剩缩略图时明确标记，详情不提供失效原图下载。保留缺失图片的设计元数据，不静默删除款式，不将缩略图冒充原图。已被旧版本删除的原文件只能从完整 uploads 备份恢复，当前未访问生产文件或执行恢复。

回归覆盖共享资产单张归档、批量归档、跨用户缩略图引用、原图字节和访问保留、同路径永久删除、缺失状态及浏览器预览回退。本修复尚未推送或部署。
