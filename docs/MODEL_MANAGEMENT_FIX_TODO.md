# 模型管理修复执行清单

日期：2026-10-20；基线：0.11.1 / `37cee76`；实施版本：0.11.2；分支：`fix/model-registry-deletion`。

## 规则

- 下架：保留在管理列表，可以再次上架，同一供应商下仍占用模型 ID。
- 删除：从管理与可用列表移除，不再接受编辑、上架、测试；允许同一供应商重新添加同一模型 ID，新记录获得新 ID。
- 账单、历史任务、生成图片及其模型关联保留。数据库保留带删除时间的历史记录，不复用旧 ID。
- 旧版只有 `is_active=0`，无法区分曾点击删除还是主动下架，不自动清除旧数据；管理员可对旧停用记录重新点击删除。
- 供应商删除同步移除其模型；停用供应商只影响可用性，不抹去各模型的上架意图。
