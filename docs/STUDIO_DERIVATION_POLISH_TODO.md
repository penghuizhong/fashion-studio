# 款式衍生界面精简与状态反馈执行清单

日期：2026-10-20（Asia/Shanghai）。状态：已实施并完成本地自检，用户已授权推送并合并 main；基于已同步的 main 0.10.1，保留原发布记录。

## 用户反馈与代码核对

- 图一圈出的区域同时包含“已关联款式 Vx 属性 / 查看属性”、自由衍生保存要求面板、版本结果说明。用户要求整块从款式衍生 tab 移除，属性编辑由款式属性 tab 管理。
- 自由衍生目前是网格外的小按钮，虽然写入了 aria-pressed，未绑定对应可见选中样式；尺寸、说明的位置和其他动作卡不同，容易误认为辅助工具。
- 弹窗右上角下载原图是 a 标签，其他操作为 button。相同 class 与 min-height 不能保证 inline 链接和原生按钮拥有一致盒模型、行高及对齐。
- 额外发现：通用 `.style-workspace button:not(...)` 样式的优先级高于 tab 的 `.active` 样式，覆盖背景、文字和字体状态；当前 tab 的可见选中反馈也受影响。
- 追加反馈：缺少底图的普通表单状态触发了自动报价请求，服务端 SOURCE_REQUIRED 被写入整个弹窗共用的 error；错误展示在所有 tab 内容之前，切换 tab 未清除/隔离，于是在属性、版本等无关页面也出现同一红框。
- 用户明确取消图文排版功能，要求整项移除，不再改造或保留为折叠/隐藏入口。

## 已实施的主流程

本次衍生（统一动作卡） → 参考图 → 本次要求 → 风格/取景/模型与输出 → 固定底部费用与确认生成。版本结果通过底部简短状态或提交后的反馈呈现，详细信息留在属性和版本 tab。

## 实施结果

- 表单已删除“已关联款式 Vx 属性 / 查看属性”、自由衍生独立保存面板和重复版本说明。自由衍生进入七项统一动作卡第一排；提供边框、底色、勾选、aria-pressed、方向键及 Home/End 操作。
- 三个标签页有独立选中状态，兜底按钮 CSS 降低优先级；顶部三个文字操作统一为 44px 同宽按钮，手机端独立成行，关闭保留在标题行右上角。
- 自由衍生报价只保存待生成快照；确认后在任务/积分事务内创建版本，使用实际最新编号。报价展示“基于 Vx，确认生成时保存新版本”，不预先承诺编号；原属性、原工作版本不变。
- 模型价格变化、报价过期、余额不足、图片失效均在提交时重新校验，失败整体回滚版本、任务与费用预留。重复请求复用原任务；失败任务重试沿用已建版本。浏览器保留未确认请求的报价及请求标识，关闭、重开或普通草稿超过 24 小时后仍可核对；不会自动重发未确认任务。
- 自动报价前检查参考、模型任务能力、尺寸、质量、数量、设计要求及取景；正常待填写状态仅在固定操作区显示简短中性说明。上传/参考、模型输出、属性、版本、报价与历史任务错误分别显示，参数改变取消过时请求；原服务端校验保留。
- 图文排版编辑器、专用样式、保存 API 方法、工作区请求与读取均已移除。旧 /layouts 读写及 /workspace/layouts 返回 410 FEATURE_RETIRED，跨用户仍返回 404。旧草稿不读取，旧面板参数归一到有效页面；历史 style_layouts 表与图片引用保护保留，无数据删除或生产迁移。
- 连续提交任务后最新任务排在首位，避免“查看最新任务结果”定位到旧任务。前后端及锁文件均为 0.10.1，依赖版本未变；当前改动记入 CHANGELOG 的 0.10.1 款式衍生优化条目。
