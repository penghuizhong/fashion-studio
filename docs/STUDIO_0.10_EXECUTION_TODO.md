来源：[本轮讨论待办](STUDIO_PERFORMANCE_UX_TODO.md)。讨论已结束，12 项实施及自检已完成，当前版本 0.10.0，实现提交 `b8dc69b`；发布记录见 [0.10.0 变更说明](RELEASE_NOTES_0.10.0.md)。保留原始讨论记录；本清单用于逐项验收，不与 0.9 的完成项混算。

## 执行决策

- 详情直接展示卡片缩略图；只取工作/查看版本和展示图，辅助数据按面板加载。分页每页 20 条，图库每页 24 条，任务轮询只取当前任务进度，完成后刷新必要结果。
- 预览长边上限 1600px，WebP 质量 82，等比缩小且不放大小图；独立保存副本，原图字节不变。旧图后台单并发补建，不阻塞首次预览。
- 缓存只记录按用户隔离的预览 URL 就绪状态（48 条、5 分钟），不持有大图解码对象，在退出/鉴权失效时清理；私有预览每次复验权限与 ETag，不使用公共缓存。原图下载保持原样。
- 六个主要动作：生成基础图、换色、改细节、出细节图、换场景、白底商品图；自由衍生为明确的新版本动作入口，再生成移至结果区。要求按动作保存草稿。
- 保留明确的版本保存动作及反馈；改变设计后先保存版本，再确认报价生成。文字设计说明不冒充结构化属性修改。
- 参考图统一为上传/图库选择，图库含当前款式、资产库、已上传；同一来源去重，按模型实际能力计数。
- 管理端提供统一价/分档价、规则表格、批量填写、可选默认价及无模型调用的服务端报价预览。历史价格无损回显，未配价格不自动回退。

## 本地性能记录

模型列表人为延迟 800ms；Chromium、本地单用户模拟、单张纯色 PNG。旧版桌面 1440×900 的 4096² 原图首次可见为冷/热 1402/1341ms。新版下表测量从自动点击到可见图片并解码完成；包含自动化往返，不能解释为纯渲染耗时。

| 条件 | 弹窗出现 冷/热 ms | 首个预览 冷/热 ms | 清晰预览就绪 冷/热 ms |
| --- | ---: | ---: | ---: |
| 桌面 1440，4096² | 111 / 80 | 167 / 106 | 176 / 111 |
| 手机 390，4096² | 331 / 61 | 372 / 83 | 384 / 88 |
| 桌面 1440，1024² | 169 / 80 | 243 / 97 | 257 / 115 |

4096² 原 PNG 为 233666 字节；冷加载 1600px 预览的 Resource Timing transferSize 约 4930 字节、请求耗时约 13–19ms，热打开未新增预览资源传输记录。1024² 原 PNG 16049 字节，对应预览传输约 2242 字节。对已就绪图片再次调用 decode 的耗时约 0.3–1.8ms，不能当作首次解码成本；纯色图的压缩比也不能代表真实服装照片。

延迟 workspace 时已单独断言缩略图在资料返回前可见；纯看图不加载模型、参考图库或报价，点击实际尺寸后才请求原图。43 个版本/47 张图片的专项验证轻量概要不携带全量历史，长度小于兼容全量响应的 1/8。以上均为本地样本，未访问生产数据，也不承诺线上固定提速倍数。

- 1600px、WebP 82、48 条/5 分钟缓存及分页 20/24 条为本轮默认，可依据真实服装图与线上指标再调整。
