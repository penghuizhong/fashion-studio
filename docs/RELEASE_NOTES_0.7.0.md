# Fashion Studio 0.7.0（未发布）

## 实施结果

- 固定弹窗标题、关闭按钮、四步导航及操作栏，正文独立滚动；桌面保持尺寸，手机接近全屏并避开底部安全区。
- 上一步和步骤导航保留参数、方案、选择和图片；只有明确发散或确认费用生成才提交模型请求。设置修改后提示旧方案仍对应上次发散。
- 创意输入与模型设置分组，高级选项默认折叠；数量快捷项与自定义同行，保留条件按需添加，锁定状态有文字标记。
- 方案卡展示编号、简短名称、设计方向和变化字段，可展开完整 DNA；支持只看差异与最多四个已选方案对比。
- 自动防抖获取服务端报价，过时响应不覆盖新报价，过期自动刷新；用户仍须明确点击确认费用，刷新不自动提交生成。
- 图片点击放大原图，收卡复选框独立；下载及收卡继续使用原文件，不裁切。收卡后留在结果页，显示已收卡并提供前往款式库。
- 历史显示缩略图、类目、时间和成功数量；切换历史可返回当前任务。按用户隔离的 sessionStorage 草稿有效期 24 小时，保存任务指针及请求键，不保存密钥或原图数据；退出登录清理。
- 发散中关闭后，完成的方案仍写回匹配请求的草稿；已有任务继续后台运行。焦点约束、Esc、关闭后回到入口及图片键盘打开已补齐。
- 拆出 ExploreModalShell 与 ExploreDnaCard，复用原图查看/下载组件。历史查询只新增展示字段，沿用原有用户范围，无数据库迁移。

## 本地验证

- 单用户：62/62；多用户：64/64；模型及图片专项：38/38。
- Chromium：14/14，生产构建通过；git diff --check 通过。
- 浏览器覆盖：主流程、锁定条件、跨类目历史、思考及自定义数量、1440×900 / 1280×720 / 720×450 / 390×844 / 375×667 的固定布局、导航零调用、草稿恢复、深浅主题、报价竞态与过期、图片查看不误选、发散中关闭恢复、旧草稿修复与字段错误关联。
- 720×450 检查相当于 1440×900 在 200% 浏览器缩放时的 CSS 可视空间；没有将设备像素比例冒充浏览器缩放。
- 截图位于当前环境 `/tmp/explore-ux-{宽度}.png` 和对应 `-dark.png`；已人工查看手机深浅主题截图。
- 原图字节与等比缩略图验证沿用专项中的真实 1000×500 图片；浏览器模拟生图不代表真实模型效果。

多用户测试有既有后台未配置 Key / fetch failed 提示，断言全部通过。实体设备安全区、完整辅助阅读器、真实供应商效果及生产人工验收仍需独立验证。
