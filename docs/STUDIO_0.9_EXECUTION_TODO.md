## 确定规则

- 使用中、归档、回收站、永久移除为独立状态；已有归档不迁入回收站。还原回移入回收站前的状态。款式隐藏时默认隐藏其资产，恢复款式不修改单张资产原有状态。
- 永久移除仅移除对象，保留必要任务/账本与版本审计；文件空间清理是单独操作，共享文件仍保留。运行中与待核对任务阻止销毁关联对象；不自动清空回收站，不自动清理生产缺图记录。
- 默认风格六项：北欧简约、海岛度假、复古美式、都市极简、自然户外、轻奢质感；单选可取消，更多折叠。只改变画面呈现；设计改变须保存设计版本，文字设计要求标记为本次要求而非已保存属性。
- 首张参考为主体，支持排序；图号绑定任务快照。参考数量以模型与适配器能力取交集，不静默丢图，不转文生图；默认无图按保存属性生成。
- 明确实现的适配器才开放输入、质量与尺寸能力；未知供应商不凭名称猜协议。迁移保留旧配置为人工声明，实测与人工声明分开展示。真实图片测试由管理员显式发起，可能有上游费用。
- 质量与尺寸分开映射到上游原生参数、服务端报价和任务快照；原图字节保留，禁止后期裁切或放大冒充原生输出。
