创意衍生第三步“生成图片”增加“整体设计规范”：默认折叠，点击或键盘展开后可编辑多行文本，支持Markdown形式的纯文本要求。新任务预置服装呈现、拍摄、视觉风格和文字标识要求；用户可修改或清空，最多8000字。具体服装设计仍以各自方案为准，视角与景别由取景设置约束。

规范参与本批每张图的实际提示词，报价和任务保存采用的文本及完整提示词。修改会立即使旧报价失效，并自动重新报价；编辑、折叠与导航不调用发散或图片模型。明确的近景或正背面冲突在报价时就地返回。费用仍按原注册模型的尺寸/质量报价，不增加额外分析步骤。

草稿、上下步、当前任务/历史往返和已生成任务恢复保留规范。旧草稿或历史任务缺少规范时按空处理，不补入新版默认值。失败重试只读显示原规范，服务端强制采用原快照及提示词；调整规范需选择方案重新渲染。重试草稿也保存来源任务，重开后不会变成普通新生成。
