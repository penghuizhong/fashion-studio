## 统一规则与冲突处理

1. 一张款式卡是容器，包含不可变设计版本；一次编辑保存一版，不按输入字符或单字段产生版本。仅输出呈现变化不强制创建设计版本。
2. 采用“款式卡 → 设计版本 → 生成批次 → 单张图片”组织数据；父设计版本与本次底图分别记录。
3. 右侧标签统一为“款式衍生 / 款式属性 / 版本记录”，替代早期“生成图片 / 生成历史”命名；入口决定默认打开模式。
4. 属性修改保存为新版本，旧版本不覆盖。“同步属性”也必须创建新版本，不能照早期建议直接改写当前属性。
5. 新生成结果不自动变成工作底图、工作版本或封面；查看历史同样不改变它们。采用拆为保留结果、设为展示图、以此继续衍生、另存新款式。
6. 正式版本属性不可变；定稿锁定具体版本，可从它创建新的未定稿版本继续设计。取消定稿只调整生命周期状态，不改写其属性快照；相关操作保留记录。
7. “回退”不删除后续版本或原图；归档可恢复，永久删除是独立明确操作。弃用已生成结果不自动退款。
8. 默认完整展示并保存模型原图，压缩预览另存；不得靠后期强裁切、拉伸或放大缩略图掩盖构图问题。
9. 只开放供应商适配器实际支持的能力；不做无效滑杆、不静默降级，不承诺 seed、参考图或提示词可保证严格一致。
10. 优先修视角与完整性，同时按依赖建立版本和任务基础，再接工作区；扩展能力单列，不因分期从总清单中删除。

## P0-A：统一视角与取景（最高优先级，可独立交付）

- [x] CAM-02 提供“标准款式对比”默认预设：正面平视、完整单品、居中和适当留白；真人中性姿态，同批候选共用设置。
- [x] CAM-03 按上衣、裤装、裙装、套装定义完整范围；套装明确上衣或整套，不把完整单品等同人物全身。
- [x] CAM-04 创意衍生渲染步和款式衍生呈现区均显示“视角与取景”，支持主动选择背面、侧面、全身或局部。
- [x] CAM-05 生成专属构图指令，解决全景/特写、正面/背面、风格预设/锁定视角等冲突；背部细节不强求在正面图中同时出现。
- [x] CAM-06 与原生尺寸联动推荐画幅；参数写入报价、快照及幂等签名，修改后重新报价，历史失败重试沿用原快照。
- [x] CAM-07 保留历史提示词和图片；老记录不能被新默认值静默重写。

验收：两条链路的参数、报价失效、快照和重试可自动验证；真实模型使用上衣、裤装、长裙、整套及方图/竖图测试，同批检查朝向、主体远近和衣物边界。真实构图效果不能以模拟接口测试代替。

- [x] VER-02 从指定版本建立草稿，一次可编辑多个字段；展示变化摘要，无实际属性变化不制造重复设计版本，保存后生成新版本。
- [x] VER-03 明确当前查看版本、工作版本和封面图片所属版本，提供显式切换；从旧版分支不删除后续设计。
- [x] VER-04 同属性多批生成不增加重复属性版本；新版本无图显示“尚未生成”，父版图片只能标为参考。
- [x] VER-05 定稿作用于版本；另存款式与卡片内新增版本分开。并发编辑保留来源，不静默覆盖其他人的工作状态。
- [x] VER-06 旧款式当前属性迁移为初始版本，图片文件引用复用；旧图缺少历史属性证据时标为未记录，不伪造与初始版本匹配的快照。
- [x] VER-07 核对现有创建、更新、克隆、创意收卡、定稿和生成 API 的兼容与所有权校验，新增版本写入采用事务和幂等保护。
- [x] VER-08 迁移可重入；升级前备份数据库及上传文件，制定应用与数据回滚方案，避免旧服务写坏新版本数据。

验收：多字段编辑只保存一版，旧版属性哈希不变；分支、并发、重复保存、迁移重跑和跨用户隔离验证通过，原图没有额外复制或丢失。
