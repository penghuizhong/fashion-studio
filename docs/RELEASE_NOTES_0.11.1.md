# 0.11.1：黑色主题与界面层级统一

日期：2026-10-20（Asia/Shanghai）。基线：main / 1df2982（0.11.0）。

## 视觉规则

黑色保持主基调。深色页面和图片画布保留纯黑，弹窗与主要面板近黑，卡片及输入控件轻微提亮，悬停与选中再增加一层明度。正文采用柔和白，辅助说明采用中性灰。

所有 UI 配色集中在 `client/src/theme.css`，含深浅主题、语义状态、图表、媒体遮罩及阴影。组件只引用语义变量；已有背景与文本别名保留，补齐此前缺失的变量。原生表单使用对应 `color-scheme`，系统默认和本机保存的主题选择保持兼容。

| 用途 | 变量 |
| --- | --- |
| 页面 | `--surface-page` |
| 弹窗、主要面板 | `--surface-panel` |
| 卡片 | `--surface-card` |
| 输入及普通控件 | `--surface-control` |
| 菜单等浮层 | `--surface-raised` |
| 图片画布 | `--surface-canvas` |
| 悬停 / 选中 / 按下 | `--surface-hover` / `--surface-selected` / `--surface-pressed` |
| 选中边框 / 键盘焦点 | `--border-selected` / `--focus-ring` |
| 正文 / 辅助 / 占位文字 | `--text` / `--text-secondary` / `--text-placeholder` |
| 主要操作 | `--accent` / `--on-accent` |
| 图片上操作 | `--media-overlay` / `--on-media` |

## 覆盖范围

- 款式详情标题栏与预览工具栏统一，下载、放大、实际尺寸等辅助操作改为轻量样式；关闭入口、触控尺寸和固定底部操作保留。
- 动作卡、步骤、标签、参考选择、项目导航等选中状态采用轻填充与细边框，去除叠加粗白描边；勾选和独立键盘焦点仍清楚可见。
- 设计台、创意衍生、资产库、样衣台、制版台及设置/模型管理共用同套层级；状态标签和统计图也使用主题变量。
- 图片颜色、格式、比例与原图文件保持原样。主题不通过滤镜、混合模式或降低图片透明度实现；预览压缩机制不变。

## 维护与验收

`npm --prefix client run check:theme` 检查组件/布局样式没有固定颜色、语义变量已定义、深浅主题有必要的基础配置。已加入验证和部署前构建工作流。服装色号等业务内容不作为 UI 配色替换。

浏览器检查主题切换与保存、真实键盘焦点、选中描边、文字对比度、原生控件、图片显示与原图字节，以及桌面/手机跨工作台布局；既有浏览器回归 55/55、最终主题专项 7/7、主题约束与生产构建通过；实际结果回填到 [执行清单](BLACK_THEME_EXECUTION_TODO.md)。

本轮不修改模型调用、计费、数据库结构或文件生命周期，无新增数据迁移。前后端及锁文件同步为 0.11.1。功能在独立分支实施，推送与合并另按用户指令执行。
