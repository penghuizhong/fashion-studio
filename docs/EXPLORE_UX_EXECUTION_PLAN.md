# 创意衍生交互体验：执行方案与验收清单

状态：0.7.0 本地实现与自检。本文将已讨论的九类建议转为执行任务；实现与发布分开记录，线上人工验收不由本地测试替代。

## 已发布基线与不可回退约束

0.6.0 已合并 main，提交 `39b00c06b2ff1bc62afe6629f53154f764feec75`，标签 `v0.6.0`。远端验证及自动部署流水线成功；真实模型效果和线上人工体验仍需单独验收。

- [x] 原图按模型返回字节保存；压缩缩略图单独生成，收卡引用原图。
- [x] 图片预览使用完整展示；款式卡可打开原图大图、下载原图，属性有独立入口。
- [x] 款式卡使用 1:1 容器并允许留白，不把原图裁成正方形。

后续所有图片视图均不得强制裁切为 3:4 或 1:1。容器比例与文件比例分开；列表优先缩略图，大图按需请求原图。保留既有所有权校验、计费幂等、任务快照和未知结果保护。

## 第一阶段：统一弹窗框架与滚动（最高优先级）

- [x] 固定标题栏、右上角关闭按钮、步骤条和底部操作栏；只有中间内容区滚动。
- [x] 去除候选列表、结果列表的独立纵向滚动，避免弹窗和卡片区域多层滚动。
- [x] 桌面弹窗保持稳定尺寸；手机采用接近全屏面板，底部适配安全区。
- [x] 底栏左侧上一步、右侧唯一主动作，中间显示选择数量、任务状态或费用。

验收：展开保留字段、展示 16 个方案并滚到底部后，关闭、步骤和操作按钮仍可见；桌面与手机均无横向溢出，页面背景不能随弹窗滚动。

## 第二阶段：完整步骤导航与状态保留

- [x] 建立四步导航：创意设置 → 筛选方案 → 生成图片 → 查看与收卡。界面步骤与后台任务状态分别管理。
- [x] 筛选返回设置时保留输入、候选及选择；渲染返回筛选保留模型、尺寸和选择；结果返回渲染保留历史图片。
- [x] 已完成步骤可点击返回，未满足前置条件的步骤不能跳转；返回查看不调用模型、不扣费。
- [x] 修改创意输入后标记方案对应旧设置；只有显式点击“重新发散”才提交新任务，旧批次仍可查看。
- [x] 生成中允许查看前面步骤，提交参数保持快照；普通“下一步”不能重复提交或重新付费。
- [x] 从结果重新生成必须明确表示新一轮任务，保留原任务和结果；不通过返回操作清空选择。
- [x] 恢复历史任务时使用该任务快照，避免覆盖不相关的当前草稿。

验收：逐条检查前进、后退、步骤条、双击和请求重试；除明确生成动作外模型调用数和费用增量均为零，旧任务快照不变。

## 第三阶段：输入分组、术语与方案比较

- [x] 第一页分为“创意设置”和“模型与高级设置”：主要输入优先，模型名称保持可发现，详细计费说明折叠。
- [x] 快捷数量与自定义数量合为一组，保留 1–16 前后端限制，去掉重复整行输入。
- [x] “发散轴”改为“希望探索哪些变化”；“锁定字段”改为“哪些设计必须保留”。
- [x] 锁定项显示“已锁定”，支持按需添加保留字段，避免一次展开大量输入；服务端锁定校验保留。
- [x] 思考模式开关紧邻标签，显示状态与模型能力限制；统一标题、输入、辅助说明和按钮间距。
- [x] 方案卡优先展示编号、简短名称、一句话方向、所选变化维度和保留条件，完整 DNA 按需展开。
- [x] 增加“只看差异”和已选方案对比；对比限制为可读数量并提示，缺失字段与低置信度有文字说明。
- [x] 选中状态同时使用底色、勾选标记和边框；全选、清空、展开详情不互相误触。

验收：手机可快速比较多个方案；锁定与变化不冲突；完整字段始终可查看，不能因摘要省略而丢失原始 DNA。

## 第四阶段：自动报价、图片查看与收卡反馈

- [x] 模型、尺寸、方案选择变化后防抖请求服务端报价；立即失效旧报价，取消或忽略过时响应。
- [x] 底栏直接显示张数、尺寸、预计积分与“确认并生成”；加载中、错误或无有效报价时禁用提交。
- [x] 报价过期重新获取；价格变化必须让用户重新明确确认，不自动生成；区分免费与未配置价格。
- [x] 创意结果卡将“查看大图”和“选择收卡”分开；显示方案编号及设计摘要，复用已有原图查看与下载组件。
- [x] 图片使用缩略图、懒加载和占位；任何预览不裁切，下载与收卡保持原始字节。
- [x] 成功、生成中、失败和待核对分别显示文字状态；保留成功图，未知结果不能自动重试。
- [x] 收卡成功保留结果页，标记“已收卡”，防止重复提交，并提供用户主动点击的“前往款式库”。
- [x] 部分收卡、重试及重复响应给出准确反馈，不生成重复款式。

验收：模拟报价乱序、过期、涨价和断网；确认前不得产生生成请求。使用横图、方图、竖图核对完整预览、下载及收卡原图哈希；不能只用单像素样例代替比例验收。

## 第五阶段：历史、草稿、关闭及无障碍

- [x] 标签改为“当前任务 / 历史记录”；历史展示缩略图、类目、时间、成功数量与状态。
- [x] 浏览历史不丢当前任务；分页与任务切换处理请求竞态，恢复正确任务及参数快照。
- [x] 草稿保存输入、选择、步骤、模型、尺寸及任务指针；按用户和版本隔离，设置有效期，退出登录清理。
- [x] 不在草稿保存凭证或原图数据；恢复时核对服务端状态。
- [x] 旧草稿中的失效类目、字段及模型安全回退并显示修复提示。
- [x] 关闭按钮和 Esc 保存草稿；遮罩点击不意外丢失内容；关闭不等于取消，已提交任务继续运行。
- [x] 断流后按任务状态恢复反馈，显示真实阶段、数量与用时，不暴露思考正文、不虚构百分比、不盲目重发。
- [x] 补齐弹窗名称、焦点约束、关闭后焦点返回；嵌套大图优先处理 Esc，步骤切换焦点移到标题。
- [x] 卡片和步骤可键盘操作，进度播报节流，状态有文字，主要触控目标至少 44 像素。
- [x] 数量与变化字段关联校验说明，数量非法时标记 aria-invalid；服务端组合错误关联整个表单警告区。

验收：关闭重开恢复现场，切换用户不泄露草稿；后台任务不重复执行。仅键盘可以完成主要流程，嵌套大图关闭后返回正确焦点。

## 实现边界与组织方式

- [x] 拆出 ExploreModalShell 统一外壳（标题、步骤、正文、操作栏）及 ExploreDnaCard；四步内容由同一流程状态控制，历史独立分区。
- [x] 集中管理导航、草稿和任务恢复，区分可编辑草稿、已提交快照与后台状态，避免多个布尔状态组合失控。
- [x] 复用 OriginalImageViewer / OriginalImageLink；优先使用局部 explore 样式，不意外改变其他公共弹窗。
- [x] 不借界面改动绕开服务端报价、幂等、权限、锁定字段校验或账本规则。
