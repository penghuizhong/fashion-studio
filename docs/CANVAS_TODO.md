# 万能画板执行清单

目标：基于两份上传文档、最初截图及后续八张流程截图，在现有 React/Vite + Express + SQLite 项目新增独立万能画板。
首个完整交付：模特图 + 服装图 → 冻结引用 → 双图真实发送 → 占位与进度 → 结果落位 → 刷新恢复。

## P0：规格与接入
- [x] 梳理现有模型、多图生成、积分、持久化任务和模特库复用边界。
- [x] 侧边栏新增万能画板，支持选中状态、移动端关闭导航、游客引导登录。
- [x] 页面按需加载，提供真实开发状态，不展示模拟成功或可用的生成按钮。
- [x] 固定 tldraw/assets 3.15.6，确认 React 18 兼容，接入带 schema 的 document 快照与迁移加载。
- [ ] 生产上线前核对 tldraw 商业许可并配置合法 license key；未代购许可。
- [x] 建立统一视口下的视觉基线：初始、单选、多选、发送、生成中、完成、保存工作流、批量面板。

## P1：基础画板
- [x] 白色画布、顶部画板栏、左图层面板、左下导航图、底部工具栏、右 Agent 面板；适配现有主题。
- [x] 画板创建、列表、重命名及所有者权限。
- [x] 缩放平移、多选、图片与文字、图层显示锁定排序、撤销重做。
- [x] document 快照与 schema 版本；防抖串行保存、expectedRevision 冲突检测及本地修改保留。
- [x] 验收：重新进入后布局一致；多标签页不静默覆盖；移动端上传与编辑入口可操作。

## P2：资产与引用
- [x] 上传、粘贴、拖拽，关联款式当前版本、商品图与我的模特，不重复复制文件。
- [x] 资产 ID、尺寸、文件可用性、所有者和资产版本；清理策略避免删除仍被画板引用的文件。
- [x] 分离画布选择、输入引用、已提交任务引用；编号不固定绑定业务角色。
- [x] 冻结 编号 → 资产 ID → 版本 → 角色 → 文件；提示词和附件使用同一来源。
- [x] 单选浮动工具栏、多选批量栏、可移除的缩略引用标签。

## P3：真实生成闭环
- [x] 提取公共生成执行能力，避免依赖假款式批次。
- [x] 持久化任务与步骤、原子认领和租约、服务端执行、SSE 通知和轮询补偿。
- [x] 服务端能力校验、报价、预算、幂等提交和结算退款；结果不明禁止自动重发。
- [x] 圆角渐变占位、任务名、耗时、停止语义、确定性结果 ID 与右侧落位。
- [x] 输入、步骤、任务、输出资产血缘；保存失败只补持久化；刷新恢复不重复放图。
- [x] 测试实际上游收到两份图片内容；重复提交不重复出图扣费；权限隔离。

## P4：Agent
- [x] 每画板单会话的 run/step 持久化、结构化工具白名单、最近四轮文字上下文、预算和单步上限。
- [ ] 多会话切换、多步工具编排。
- [x] 空态分类与示例、消息流、处理方案、调用中、任务进度、完成卡片与结果缩略图。
- [x] 发送后保留引用，支持移除及重新选择；停止、失败、断线和重启恢复。
- [ ] 完成后引用标签自动清空的精确时机继续与原站校准。
- [x] 核心验收：图1模特、图2服装，保持模特特征并完成双图换装。

## P5：工作流与批量
- [x] 从成功运行保存单步结构化流程，输入槽位参数化；确定性执行，避免依赖 LLM 重述参数。
- [ ] 多步骤工作流（当前首版每个工作流生成1张图）。
- [x] 名称、删除、已保存状态、数量、批量面板、商品选择、预算和独立失败处理。

## P6：工具与产品化
- [x] 原生文字、图片裁剪、PNG导出、前后对比、品牌套件、7天可撤销只读分享。
- [ ] 专用局部遮罩、抠图、AI超分和扩图：现有能力契约未提供专用接口，保留待接入。
- [ ] 视频、技能及团队执行单独评估，不用未接通的菜单冒充可用功能。
- [x] 现有款式衍生、模特库回归；构建、主题、相关后端检查与浏览器验收。

## 证据与待核实行为
已见：单选紫框和尺寸、多选整体框及批量栏、编号引用、调用模型、方案说明、渐变占位、进度耗时、停止、完成缩略图、存为工作流及批量预算面板。
未见：对比展开、模型及更多工具菜单、分享和导出弹窗、失败及余额不足、移动端。截图不能证明生成后自动缩放，也不能确定主画布来源线的渲染规则；缩略导航中可见来源连接。
文档骨架需修正：revision 条件更新、任务原子认领、扣费及退款幂等、真实多图附件、安全资产代理。

每阶段完成后更新本清单并提供可操作结果与检查记录。推送部署遵循用户明确指令。
