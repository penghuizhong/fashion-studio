## A. 模型调用与报价

- [x] 第一页显式选择发散模型，默认后台推荐，本次选择不改全局设置。
- [x] 用注册模型 ID 解析所属供应商、协议、凭证与价格；同名上游模型无歧义，禁止跨供应商凭证回退。
- [x] 平台与完整 BYOK 连接分流，模型和供应商启用校验；图片支持 DashScope / OpenAI 兼容协议，不把其他协议误发到图片接口。
- [x] 发散不要求图片模型；图片模型与尺寸移到独立渲染步骤。
- [x] 服务端按真实选择报价，校验尺寸，缺失价格与显式免费区分；价格变更/过期须重新确认。
- [x] 保存发散模型、类目/字段/规则、锁定值与版本；每次生图保存模型/价格/尺寸/提示词/seed 快照。
- [x] OpenAI 图片地址规范化，避免重复 `/v1`；结构化安全错误码与请求编号，供应商授权错误不会让用户退出登录。

## B. 任务、费用与数据一致性

- [x] select 仅允许修改未开始生成的批次，不能重置渲染中、已渲染、已收卡状态。
- [x] 发散和生成请求幂等；报价只能使用一次，异参复用请求键拒绝；数据库约束阻止并发重入。
- [x] 每张图片独立状态、提示词、结果和费用；供应商同时最多两张，异步提交、轮询进度、历史恢复。
- [x] 统计区分额度预留、退款和实际结算，避免把退款记成赠送、把预留记成消费。
- [x] 平台原子预留额度；成功保存后结算；明确失败释放额度，不再吞掉扣费错误。
- [x] 超时、断网、进程中断区分未执行项与未知结果，未知项阻止自动重发；租约过期恢复与结算状态防护。
- [x] 管理员模型管理页增加费用核对区：填写依据后退款、解除阻塞；旧版卡住的批次可单独核对恢复，旧账本不自动改写。
- [x] 只重试明确失败项，重新报价并保留原提示词/seed，既有成功图继续保留；新生成任务与历史记录分开。
- [x] 收卡先验证全部索引、成功图片与所选历史任务，事务写入并去重；不会把新图片误收为所查看的旧图片。
- [x] 多用户图片及缩略图校验会话与所有权，私人资源不使用公共缓存。

## C. 发散与提示词质量

- [x] `expand_prompt` 加列迁移、后台编辑与 API 读写；与识图 `prompt` 分离，seed 不覆盖管理员值。
- [x] 结构化锁定字段，不能与发散轴冲突；自然语言意图保留，提示词明确用户要求优先。
- [x] 严格检查候选数量、完整字段键、类型、confidence、锁定值及轴组合差异；最多一次格式修复，记录真实用量，失败发散退款。
- [x] 九类 mock 在 6/8 候选时仍互异；mock 用于流程验证，不表示真实设计质量。
- [x] 新增 `dnaRenderProfiles`，覆盖西装 seed 中的版型、驳头、扣型、开衩、面料、图案、风格、细节和场景词汇；其他类目有主体和安全回退。
- [x] 提示词保留客户意图、去重且不修改 DNA；历史展示使用保存字段，重试按原提示词执行，新渲染明确生成新快照。

## 0.5.0：发散实时反馈、思考模式与自定义数量

- [x] 改为上游流式 JSON 接收 + 浏览器 SSE，显示真实阶段、用时、字符数和已收到候选数；每 3 秒心跳，关闭反代响应缓冲。
- [x] 实时反馈只包含元数据，不向浏览器发送模型思考内容；输出完整校验通过后才显示方案卡。
- [x] 记录模型首响应、首段输出、总耗时与尝试次数，明确告知格式修复重试，不再只显示“正在发散”。
- [x] 默认关闭思考，支持按协议开启/关闭；强制推理或不支持切换的模型明确展示能力限制，自定义协议说明尽力支持。
- [x] 保留快捷数量并增加自定义 1–16，前后端一致校验；输出预算和积分预留随字段数、数量、思考设置调整。
- [x] 紧凑 JSON 与较低采样温度减少冗余输出、格式失败风险；只保留一次显式格式修复，不盲目重试中断请求。
- [x] 思考设置写入幂等参数和快照，阻止同一请求键换参数复用；进行中禁用配置编辑。
- [x] 流式服务端/客户端解析、真实进度、思考参数、数量边界、异常和浏览器路径专项验证。

实现不能保证供应商推理加速；真实模型的队列、首字延迟和吞吐需要实际调用的新耗时记录确认。此轮已随 0.5.0 推送并合并 main。

本轮自检结果：单用户 62/62，多用户 64/64，专项集成 36/36，Chromium 5/5，生产构建通过。专项覆盖分块 UTF-8/SSE 接收、真实输出计数、思考参数与强制推理、数量 1/3/16 及非法边界、客户端断流、思考文本不外泄。使用模拟供应商响应，不代表线上模型耗时。
