# Fashion Studio 0.10.0

本地实施完成，依据 [执行清单](STUDIO_0.10_EXECUTION_TODO.md) 收敛设计台预览性能、款式衍生表单与模型分档计费。尚未推送、合并、打标签或部署。

## 主要变化

- 打开款式卡立即复用卡片缩略图，款式概要、模型与图库分别按需加载，辅助接口失败不遮住图片。纯看图不请求模型列表、参考图库或生成报价；关闭/切换时中止过期读取。
- 图片采用缩略图、1600px 等比预览、原图三级展示。新图保存独立 WebP 预览；旧图仅在需要时后台单并发补建，队列最多 100 项，失败保留缩略图并允许重试。预览失败不丢弃已成功保存的原图，不裁切、不放大小图，不改变原图下载字节。
- 详情首次只取工作/查看版本、展示图和必要任务摘要；版本、结果、任务、排版按需分页，图库搜索及分页在服务端进行。生成只轮询任务变化，分批完成时刷新结果。分页保留选择、父版本标注，继续衍生不因补取版本资料而切换到另一张底图。
- 预览 URL 就绪记录按用户隔离，最多 48 条、5 分钟，不在应用内长期持有解码大图。退出/会话失效与图片修改清理记录；静态图片及预览使用私有缓存复验，每次服务器请求先鉴权再处理 ETag。原图下载继续不缓存。回收站不会删除共享原图，显式清理无引用文件时同步清理预览。
- 参考区只保留上传图片、从图库选择两个入口。图库统一当前款式、资产库、已上传，支持缩略图、多选、搜索、分页和稳定来源去重，统一图号与主体顺序。限制采用模型实际可用能力；切换兼容模型时提醒重新确认报价。
- 要求区保留一个主输入框和关联属性入口；移除“包含服装设计变化”和重复拼接属性的工具，避免重复提示词及长文静默截断。各动作保留要求、目标、取景等草稿；保存与生成有明确状态。
- 六个主要动作包含白底商品图，再生成放到结果区；自由衍生通过明确入口保存新设计说明版本，原属性不覆盖、不假装自动更新结构化 DNA。白底任务统一纯白背景、去除场景型预设与继承场景提示，明显冲突的背景要求会提示调整。
- 图片计费改为统一单价或可视化规格表，支持尺寸/质量选择、可选默认价、覆盖规则、增删档位、批量填价和服务端报价预览。手机按档位显示卡片，深浅主题使用统一控件。旧规则无损回显；漏配不回退到旧单价，不自动按免费处理。
- 价格保存校验重复、交叉冲突、失效能力和非整数/负数；0 明确表示免费。价格预览不调用供应商、不扣费。模型价格更改后，旧生成报价需要重新确认。Validate 工作流加入新增专项。

## 验证与限制

后端：单用户 62/62，多用户 64/64，创意 38/38，款式 14/14、安全计费 12/12、迁移 5/5，模型/生命周期 22/22，新预览/UX/计费专项 15/15。浏览器全量 40/40，最后新增底图保持用例并定向回归 5/5，当前 41 个不同用例；生产构建、版本及锁文件一致性、Git 空白检查通过。详见执行清单的命令与测量说明。

本地 4K 纯色 PNG、模型列表延迟 800ms 的桌面样本：首图从旧版约 1.4s 降至约 0.17s；该样本仅验证解除辅助接口等待与分级加载，不代表真实照片压缩比或线上速度。另覆盖 1024px、手机、受限网络、大量历史、过期响应、权限及原图字节校验。

本轮不新增数据库列或变更历史图片、版本、账本。兼容旧 workspace、旧白底草稿与已存分档规则；现有无效规则需管理员在界面明确修正。预览文件可重建，原图不可由其还原。真实模型出图遵从、供应商计费与实体设备效果未实测，生产缺失原图未恢复。

本地回退可切换旧代码，数据库历史仍保留；独立预览不会影响旧版本读取原图。上线前仍按既有流程备份数据库与 uploads，并核对进行中/待确认任务；不能通过回滚删除原图或丢弃账本。本文不表示远端验证或部署成功。
