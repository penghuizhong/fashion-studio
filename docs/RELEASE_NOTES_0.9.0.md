# Fashion Studio 0.9.0

本轮依据 [执行清单](STUDIO_0.9_EXECUTION_TODO.md)，合并尺寸、参考图与风格表单、管理员模型配置以及内容生命周期讨论。0.8.0 已合并 main；本轮发布包含实现提交 `4be9bce`，版本标签为 `v0.9.0`。推送与合并结果以远端 Git 引用为准，线上部署状态以工作流实际结果为准，本地通过不代表已上线。

## 行为变化

- 图片调用通过平台模型记录绑定供应商、上游 ID 及实际图片协议，不再通过聊天供应商预设推断图生图能力；移除底层按同名上游 ID 首个匹配的路由。支持现有 OpenAI Images、DashScope 文生图及新增 DashScope 原生多模态图像请求适配器。原生多模态路径及数据格式已由模拟上游检验，尚未对真实供应商进行视觉验收。
- 管理员可配置参考图总上限、无图/图片输入、固定尺寸或自定义边长/倍数/像素限制、原生质量档位、按尺寸/质量计价、任务优先模型。OpenAI Images 支持安全相对路径、返回格式及 seed 参数开关，兼容不接收某些标准参数的图片服务。
- 模型连接列表与实际功能测试分开：管理员显式确认后测试绑定供应商的聊天、文生图、单图编辑或多图参考；可能有上游费用，不扣普通用户积分。保存模型不自动生图。测试记录配置签名、状态、时间、脱敏错误和管理员预览；改配置/连接后显示需复测。模拟模式明确标记“仅模拟”，不记为真实通过。验证失败的对应任务在业务界面禁用，复测通过或配置变更后重新判断。
- 创意及款式共用比例、原生尺寸、自定义宽高/比例锁定与质量控件。仅开放当前协议及模型声明支持的档位，服务端再次验证。参数变更刷新报价；任务及失败重试保留原尺寸、质量、图序与提示词；分档价格缺失或冲突阻止生成，不按免费处理。分档计费模型显示以报价为准。
- 款式界面移除“生成方式”，统一为参考图队列及本次要求。首张为主体，支持多文件上传、原始图/已有款式图片/资产选择、排序和移除，编号顺序写入实际请求。超出模型上限不静默丢图，也不偷偷退回文生图；需要切换模型时明确通知并重新报价。
- 出图用途整合入动作和白底选项；风格改为六个默认文字选项、更多折叠、单选可取消。风格只调整呈现，详细取景和必须保留折叠，细节动作展开必要取景。多张时按需显示“保持款式一致”，说明仅提示词约束。
- 自由文字包含服装设计变化时，可以保存不可变的文字设计要求版本。原结构化属性不假装已自动识别更新；界面提示待人工核对。生成快照保存该要求，保存属性和生成图片仍为不同动作。
- 款式、单张资产及创意历史提供独立使用中/已归档/回收站状态。款式卡左上角操作菜单支持重命名、更换展示图、另存、归档、回收站；支持恢复原始参考为展示图。资产可批量归档、移入回收站及还原。回收站还原到先前状态，不自动清空；款式隐藏时默认资产列表隐藏关联图片，不改写单张图片原有状态。
- 永久移除要求回收站状态、明确输入确认并展示影响范围。只移除记录，必要设计、任务与账本保留为审计；生成中和待核对项阻止销毁。未引用文件清理为独立确认动作，共享原图/缩略图、底图、排版、参考、历史任务或报价引用仍保留。文件暂存失败会回滚；新增文件引用在写事务内复查可用性。
- 创意历史统一缺图占位、本地可读日期、真实生成成功数和当前可用原图数。原图缺失不提供下载或重新收卡，缩略图不能冒充原图。归档/回收站中的已收款式可恢复，永久移除后允许重新收卡，避免 adopted_json 永久指向坏卡。

## 迁移与部署

新增款式、图片及批次的 lifecycle / restore_lifecycle，设计版本的不可变 design_note，以及模型测试和生命周期事件表。既有图片归档仍为归档，旧 user_rating=deleted 为已移除；旧批次 archived 标记保留。升级不会清理缺图卡、重写原图或删除上传文件。

有存量款式且首次增加生命周期列时，迁移前使用 VACUUM INTO 创建可读数据库快照（若同次已有版本迁移备份则复用，不重复快照）。这不能替代完整 uploads 备份。现有自动部署已在更新代码前根据实际服务数据目录停止写入并备份数据库及 uploads，备份失败不更新代码。本轮没有执行生产升级、生产恢复或真实付费模型测试。

同时修复旧用户邀请码补填迁移中错误调用未定义 mk() 的问题，改为已有安全邀请码生成器；重启回归核对唯一性、积分不重复变化及备份幂等。

模型原有能力配置作为人工声明保留。未知接口不能自动推断能力；管理员应按供应商实际文档选择协议、参数、尺寸和计价并分项测试。不支持 /models 的供应商仍可手工登记模型。供应商与模型下架/删除保留历史注册信息，已开始的任务沿用确认时的配置，不暗中更换供应商。

## 验证

测试均使用临时数据库、测试图片和模拟上游；真实适配器参数及计费路径有断言，未使用真实账户 Key。详细结果在执行清单中记录。单用户 62/62，多用户 64/64，创意 38/38，款式 14/14，安全计费 12/12，原迁移 5/5，新增模型/生命周期/升级专项 22/22；Chromium 桌面/手机流程 28/28，生产构建和差异空白检查通过。浏览器隔离夹具为集中测试调整回归写入配额，生产默认限流未修改。

## 边界与回滚

- 图片输入接口成功不能证明服装、文字或多图引用被严格遵从；质量、seed 和提示词不保证一致性。原生多模态及各质量档位需管理员使用真实服务分项检查效果和收费。
- 当前不实现蒙版或未知协议的自动兼容；质量仅适用于已实现参数映射的协议。配置了自定义尺寸仍应遵守具体供应商实际限制，不能仅凭模型名称批量开启。
- 旧版已删除的原图只能按真实备份恢复；本轮提供管理入口和缺失状态，不自动重生成或以缩略图替代。生产备份是否包含所需历史文件尚未核对。
- 模型测试预览保留供管理员审查，不提供自动清除策略；回收站及任务审计亦不自动清空。
- 回滚优先向前修复。必须回滚时停止写入、核对任务及积分预留，保留上线后数据库和新增原图的独立副本，恢复经过核对的匹配数据库/上传目录快照；不能只切回旧代码并丢弃新增生命周期和设计要求。
